# 安卓手机任务自动化脚本

基于 **uiautomator2（USB 控制 + 无障碍节点）+ CnOcr（屏幕文字识别）** 的安卓手机自动化脚本，PC端通过USB连接安卓手机，在PC端执行脚本，通过"截图 OCR 识别 + 无障碍节点查询"双通道理解屏幕内容，模拟真人操作（随机轨迹、随机压力、随机等待）完成 App 活动页的浏览类任务与连续长按升级操作。

> ⚠️ 本项目仅供个人学习与技术研究，请勿用于商业用途。使用风险见文末[风险提示](#风险提示)。

## 脚本功能

| 脚本 | 功能 |
|---|---|
| `auto_browse.py` | 在活动"任务大厅"自动完成浏览类任务：自动识别并点击"浏览N秒"任务的"去完成"按钮，自动处理跳转后的三种页面（常规浏览页、搜索页、浮窗/底部进度条页），完成后自动返回任务大厅继续下一个，直到无任务可做 |
| `auto_upgrade.py` | 在活动首页长按升级按钮消耗能量自动升级；自动识别并关闭升级途中弹出的"解锁新装备"选择弹窗；能量低于阈值自动停止 |

**两个脚本的共同特性：**

- 状态机架构：初始状态校验 → 任务大厅找任务 → 前往执行 → 执行 → 返回大厅，状态与页面不匹配时自动容错（多次返回失败则安全退出）；
- 双通道页面识别：优先无障碍节点查询（快、精确），自动回退 OCR 截图识别（兼容 H5 页面）；
- 拟人化操作：贝塞尔曲线滑动 + 低频漂移 + 随机压力注入 + 全流程随机等待，降低机器行为特征；
- 完整日志：控制台输出与每次 OCR 识别结果（含坐标）全程留档到 `.log` 文件，便于排查问题；
- 屏幕适配：页面识别与坐标判定均按屏幕比例换算，不依赖具体分辨率。

## 环境要求

- Windows / macOS / Linux（在 Windows 11 + PowerShell 下测试通过）
- Python **3.12+**
- 安卓手机：已开启 **USB 调试**，用 USB 线连接电脑，并已安装目标 App
- 首次通过 USB 连接使用 uiautomator2 时，uiautomator2 3.7.0会推送 u2.jar 到 /data/local/tmp/ 并以 app_process 启动，不安装任何 App（旧版 2.x 可能会安装 ATX App，因此建议使用uiautomator2 3.7.0版本）

## 安装依赖

> 建议在虚拟环境中安装依赖（如果你不了解虚拟环境是什么，直接在系统 Python 中安装通常也可以）。脚本启动时会自动检查核心包版本，与已验证版本不符会打印提示。

方式一：使用版本清单安装（推荐）

```powershell
pip install -r requirements.txt
```

方式二：手动安装（注意固定版本）

```powershell
pip install uiautomator2==3.7.0 cnocr==2.3.3

# ⚠️ 建议固定 rapidocr 版本（3.10+ 与 cnstd 不兼容，会报 ImportError）
pip install rapidocr==3.9.2
```

## 使用方法

1. **配置目标 App 包名**（仅 `auto_browse.py` 需要）：打开脚本，把顶部 `TARGET_APP_PACKAGE = ""` 填入你的 App 包名：

```powershell
# 不知道包名时，用 adb 查询: adb shell pm list packages
# 例如: TARGET_APP_PACKAGE = "com.xxx.xxx"
```

2. 手机连接电脑，停留在对应页面：
   - `auto_browse.py`：活动"任务大厅"页（或其上级活动页，脚本会自动点击入口按钮进入）；
   - `auto_upgrade.py`：活动首页（能看到升级按钮）；

3. 运行脚本：

```powershell
# 激活虚拟环境后
python auto_browse.py    # 自动做浏览任务

python auto_upgrade.py            # 自动长按升级(能量低于 5000 时停止)
python auto_upgrade.py 3000       # 可选参数：指定能量阈值，低于 3000 时停止
```

4. 运行日志保存在脚本同目录的 `auto_browse.log` / `auto_upgrade.log`（每次运行自动覆盖），出现异常时查看该文件即可定位问题。

## 注意事项

- **活动文字特征**：脚本通过识别页面上的文字特征（如"去完成"、"浏览N秒"、任务大厅标题等）来理解页面，这些关键词集中在脚本顶部的配置区。**App 改版或活动下线后，需对照实际页面文字更新脚本顶部的关键词配置**；
- **H5 页面**：活动页大量使用 H5 渲染，无障碍节点读不到内容，脚本会自动回退到 OCR 识别（速度约 2~4 秒/次，属正常现象）；
- **OCR 容错**：文字匹配采用子串方式，可容忍 OCR 的少量识别错误；若日志中频繁出现"未识别到"类提示，多为页面文字已变化；
- **尽量不要在脚本运行时操作手机**，避免页面状态与脚本判断不一致。
- 考虑到本脚本未对不同手机做兼容性测试，可能在不同设备上执行情况有区别，建议在执行时密切关注手机上显示的实际结果，确保脚本行为符合预期，在powershell下可通过ctrl+C中断脚本。
